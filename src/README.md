This folder contains reusable Python functions used in the analysis.
The compute_dci function is used to get the development capacity index using several social economic indicator to aggregate the score of a coutry's development, combining them together.
The eco_stab_func is used to get the stability of a country's economic using inflation rate indicator, applying volatility formula of standard deviation.
The indicator_rank is used to get the rank of coutries by the value of any interensted indicator, while in thev function GDP was the indicator of interest, it can be change to other indicators.
